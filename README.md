### привет

Учусь на ML, а параллельно почти каждый день что-то собираю руками: боты, сервисы, свою инфраструктуру. Не фронтендер и не «фуллстек за неделю» — просто нравится доводить вещь до состояния, когда она реально работает и ей можно пользоваться, а не просто лежит в папке с недоделанным кодом.

Дома стоит свой сервер на двух видеокартах (P104-100 — бывшая майнинговая карта уровня GTX 1070 Ti, и GTX 1650) — на нём же обучаю то, что можно обучить локально, без облака. Отдельно держу свой VPN на арендованном VPS (VLESS+Reality, AmneziaWG, DNS-фильтрация через AdGuard Home) — с него, собственно, и начался интерес к серверам и Linux.

**Сейчас в работе:** Focus — система контроля времени в коротких видео (бот + Android-приложение + расширение браузера, четыре компонента синхронизируются между собой), и первый настоящий шаг в сторону ML поверх уже работающих проектов — свой классификатор на NumPy для одного реального сайта.

**Стек:** Python (Flask/FastAPI), Docker, администрирование Linux-серверов, немного Kotlin/Android, PostgreSQL/SQLite, YOLO/OpenCV, Whisper/Qwen для распознавания речи. ИИ-инструментами пользуюсь как частью процесса — свериться по вопросу, ускорить рутину — а не вместо собственной головы.
